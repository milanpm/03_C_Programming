# AGENTS.md

## C Source File Header

Every C source file created in this repository must begin with the following header:

```c
/*
 * File: filename.c
 * Description: A concise description of the file.
 * Author: Alex
 * Date: YYYY-MM-DD
 */
```

## Blogger Post Section Layout

Use horizontal rules to separate the major numbered sections of C Programming blog posts.

### Format

Place `<hr />` immediately before each major `<h2>` section:

```html
<hr />

<h2 id="section-id">1. Section Title</h2>
```
